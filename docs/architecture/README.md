# Architecture

Architectural decisions are recorded as ADRs in [decisions/](./decisions/).

| ADR | Title | Status |
|---|---|---|
| [ADR-001](./decisions/ADR-001-database.md) | Database Selection (PostgreSQL 17) | Accepted |
| [ADR-002](./decisions/ADR-002-notification-processing.md) | Initial Processing Model (synchronous, evolving to asynchronous) | Accepted |

Each ADR contains: Status, Context, Decision, Alternatives Considered and Consequences. A decision is changed by writing a new ADR, not by silently editing an accepted one.
